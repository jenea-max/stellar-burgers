# Stellar Burgers

## Описание проекта

Stellar Burgers — это веб-приложение для заказа бургеров. Пользователи могут собирать свои бургеры, выбирая ингредиенты, оформлять заказы и отслеживать их статус. Проект разработан с использованием современных технологий, таких как React, Redux и TypeScript. Проект также включает тестирование с использованием **Jest** (для модульных тестов) и **Cypress** (для end-to-end тестов).

## Основные функции

- **Сборка бургеров**: Пользователи могут перетаскивать ингредиенты для создания своего уникального бургера.
- **Оформление заказов**: Возможность оформить заказ и отслеживать его статус.
- **Авторизация**: Регистрация и вход в систему для сохранения истории заказов.
- **История заказов**: Просмотр всех ранее сделанных заказов.

## Технологии

- **React**: Библиотека для построения пользовательского интерфейса.
- **Redux**: Управление состоянием приложения.
- **TypeScript**: Добавление типизации для повышения надежности кода.
- **WebSocket**: Реальное время для отслеживания статуса заказов.
- **CSS Modules**: Стилизация компонентов.
- **Jest**: Фреймворк для модульного тестирования.
- **Cypress**: Фреймворк для end-to-end тестирования.
